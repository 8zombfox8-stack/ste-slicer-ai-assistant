# STE Slicer AI Assistant

ИИ-ассистент для слайсера **STE Slicer** (Stereotech): автоматический подбор параметров FDM 3D/5D-печати по
описанию детали и техническому заданию. Решение кейса хакатона «Открой Моспром» (Росатом Аддитивные технологии,
Stereotech).

**Как это выглядит:** пользователь прикладывает STL и ТЗ в Word и пишет «Подготовь деталь к печати по ТЗ» —
ассистент сам загружает модель, анализирует геометрию, подбирает материал по базе свойств, выбирает режим 3D или
5D, ориентирует деталь, проверяет её перед печатью, нарезает и сохраняет проект 3MF, G-code и технологическую карту.
Каждое действие видно в чате, каждое решение обосновано.

## Ключевые идеи
- **Решение принимает не нейросеть по памяти, а проверка по базе свойств материалов** — с причиной отказа для
  каждого исключённого материала и источником данных («PETG — Tg 77 °C < 85 °C [Ultimaker / TU Dresden]»).
- **Интерактивная работа по 7 этапам**: уточняющие вопросы с вариантами ответа, карточка после каждого этапа,
  правки одной фразой, «Стоп / Продолжить»; объяснения простым языком.
- **5D без ручной настройки**: ось вращения, центровка, режим Spiral / Spiral Full и диаметр базы по отверстию детали.
- **Предполётная проверка** до печати вместо пробных печатей.
- **Экономика**: сравнение вариантов по времени, массе и стоимости в рублях.
- **Повторяемость**: технологическая карта и рецепты.

## Быстрая установка
1. Установите **STE Slicer 7.10**, запустите его один раз и закройте.
2. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив целиком.
3. Запустите **`install.bat`** в распакованной папке — плагин скопируется в
   `%APPDATA%\steslicer\<версия>\plugins\AIAssistant` (старая версия плагина заменяется), а на рабочем столе и в
   меню «Пуск» появится приложение **«AI Assistant»**.
4. Запустите **«AI Assistant»**: приложение откроет STE Slicer и окно чата (отдельное окно без браузерной
   панели: Edge → Chrome → Яндекс Браузер в режиме приложения; если их нет — браузер по умолчанию).
   Добавьте в слайсере принтер **Stereotech Hybrid 530 V5.2.4** (Настройки → Принтер → Добавить принтер).
5. В окне «Настройки» чата укажите Base URL, API key и модель LLM.
6. Для 5D-режимов STE Slicer попросит активацию (окно ATSS) — по инструкции организаторов.

Слева в окне чата — **проекты**: папки любой вложенности и чаты в них (создать, переименовать двойным щелчком,
перетащить, удалить). История каждого чата сохраняется в `Документы\STE_AI_results\workspace`.

> **Предупреждение Windows при первом запуске.** `install.bat` и `AI Assistant.exe` не подписаны цифровой
> подписью, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажмите **«Подробнее» →
> «Выполнить в любом случае»**. Установщик снимает пометку «скачано из интернета» с установленных файлов, и
> дальше предупреждение не появляется. Исходный код программы-ярлыка — `launcher/AIAssistantLauncher.cs`,
> пересобрать её можно командой `powershell -ExecutionPolicy Bypass -File launcher\build_launcher.ps1`.

Ручная установка: скопируйте папку `AIAssistant` в `plugins` папки конфигурации слайсера
(Справка → Показать папку конфигурации) и перезапустите слайсер; чат открывается через меню
**Расширения → AI Assistant → Открыть чат**.

## Структура
- [`AIAssistant/`](AIAssistant) — плагин для STE Slicer: возможности и устройство описаны в
  [AIAssistant/README.md](AIAssistant/README.md).
- `install.bat`, `install.ps1` — установка плагина и приложения одним запуском.
- [`launcher/`](launcher) — приложение «AI Assistant»: готовый `AI Assistant.exe`, исходник на C#, значок и
  скрипт сборки (используется компилятор из .NET Framework 4, входящий в Windows 10/11).

## Требования
- Windows, STE Slicer 7.10 (Python 3.5 внутри). Внешних зависимостей нет.
- Доступ к OpenAI-совместимому API с поддержкой tool calling (ключ вводится в чате и хранится в настройках
  слайсера, в репозитории ключей нет).
- Интернет для запросов к LLM.
