# STE Slicer AI Assistant

ИИ-ассистент внутри слайсера **STE Slicer** (Stereotech): готовит деталь к FDM 3D/5D-печати для начинающего
пользователя. Решение кейса хакатона «Открой Моспром» (Росатом Аддитивные технологии, Stereotech).

**Как это выглядит:** в слайсере есть вкладка **«AI Ассистент»**. Пользователь прикладывает модель (STL) и, если
хочет, фото, пишет пару слов — «Шестерня для редуктора» — и отвечает на несколько простых вопросов кнопками.
Остальное ассистент делает сам: подбирает материал по базе свойств, выбирает режим 3D или 5D, ориентирует деталь,
проверяет её перед печатью, нарезает и сохраняет проект 3MF, G-code и технологическую карту.

## Для новичка
- **Простые вопросы вместо настроек.** Нагрев и с чем деталь соприкасается — всегда; гибкость, как работает, что
  важнее — только если это неясно. У каждого вопроса кнопки-варианты и поле «Свой вариант»; пустой вопрос
  ассистент решает сам. При необходимости он задаёт дополнительные вопросы (посадка на вал, нагрузка и т.п.)
  и предлагает способ печати с пометкой «(рекомендую)».
- **Минимум слов.** Ход работы — одной строкой «Выполнено шагов», подробности раскрываются по щелчку.
- **Этапы работы.** Ассистент ведёт деталь по 7 этапам и пишет отчёт по каждому. По умолчанию отчёты скрыты;
  «⋯» → «Этапы работы: показывать» показывает их, и ассистент ждёт «Продолжить» после каждого этапа.
- **Технические подробности** («⋯» → «Технические подробности») — принтер, режим, материал, реплики ассистента и
  итоговая сводка.

## Под капотом
- **Решение принимает не нейросеть по памяти, а проверка по базе свойств материалов** с источником каждого
  значения (Ultimaker / TU Dresden, Prusa Material Guide, профили Stereotech).
- **5D без ручной настройки**: ось вращения, центровка, режим Spiral / Spiral Full и диаметр базы по отверстию.
- **Предполётная проверка** и **проверка режима печати** по профилю производителя до нарезки.
- **Принцип минимальных изменений**: профиль производителя меняется только там, где это требует задача.

## Установка
1. Установите **STE Slicer 7.10**, запустите его один раз и закройте.
2. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив целиком.
3. Запустите **`install.bat`** — плагин скопируется в `%APPDATA%\steslicer\<версия>\plugins\AIAssistant`
   (предыдущая версия плагина заменяется).
4. Запустите STE Slicer — он откроется на вкладке **«AI Ассистент»**. Добавьте принтер
   **Stereotech Hybrid 530 V5.2.4** (Настройки → Принтер → Добавить принтер), если его ещё нет.
5. В меню **«⋯» → «Настройки подключения к ИИ»** укажите Base URL, API key и модель LLM.
6. Для 5D-режимов STE Slicer попросит активацию (окно ATSS) — по инструкции организаторов.

> **Предупреждение Windows.** `install.bat` не подписан, поэтому Windows может показать «Система Windows защитила
> ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**.

Ручная установка: скопируйте папку `AIAssistant` в `plugins` папки конфигурации слайсера
(Справка → Показать папку конфигурации) и перезапустите слайсер.

## Структура
- [`AIAssistant/`](AIAssistant) — плагин для STE Slicer; устройство описано в
  [AIAssistant/README.md](AIAssistant/README.md).
- `install.bat`, `install.ps1` — установка плагина одним запуском.

## Требования
- Windows, STE Slicer 7.10 (Python 3.5 внутри). Внешних зависимостей нет.
- Доступ к OpenAI-совместимому API с поддержкой tool calling (ключ вводится в чате и хранится в настройках
  слайсера, в репозитории ключей нет).
- Интернет для запросов к LLM. Корневые сертификаты для HTTPS поставляются с плагином (`agent/cacert.pem`), поэтому
  соединение работает и на компьютерах с устаревшим списком сертификатов Windows.
