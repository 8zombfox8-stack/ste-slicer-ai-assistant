# AI Assistant для STE Slicer

Плагин добавляет в STE Slicer (Stereotech, форк Cura 3.6) вкладку **«AI Ассистент»** с чатом на LLM для
начинающих. Пользователь прикладывает модель (STL/OBJ/3MF), при желании фото, пишет пару слов и отвечает на
простые вопросы кнопками — ассистент сам выбирает материал, режим 3D/5D, профиль и настройки, ориентирует модель,
нарезает, сохраняет проект и G-code.

## Установка
Автоматически: запустите `install.bat` из корня репозитория (STE Slicer должен быть хотя бы раз запущен).

Вручную:
1. В STE Slicer: **Справка → Показать папку конфигурации** (обычно `%APPDATA%\steslicer\7.10`).
2. Скопируйте папку `AIAssistant` в подпапку `plugins` — должно получиться `...\plugins\AIAssistant\plugin.json`.
3. Перезапустите STE Slicer: он откроется на вкладке «AI Ассистент». Принтер — Stereotech Hybrid 530 V5.2.4.

## Настройка
В панели чата: **«⋯» → «Настройки подключения к ИИ»** — Base URL, API key и модель (OpenAI-совместимый API),
папка для результатов и стоимость машинного часа. Ключ хранится в настройках слайсера (`steslicer.cfg`), в коде его
нет. Там же в меню: удалить чат, папка с готовыми файлами, «Этапы работы», «Технические подробности», окно проектов и
папок (браузерный чат: **Расширения → AI Assistant → Открыть чат в отдельном окне**).

## Возможности
- **Вопросы для новичка**: шесть основных вопросов с вариантами-кнопками и полем «Свой вариант» (нагрев и контакт —
  всегда, остальные — если неясно), до трёх дополнительных по ходу работы, способ печати с пометкой «(рекомендую)».
  Пустые ответы ассистент решает сам.
- **7 этапов** с отчётами: задача → модель → материал → способ печати и положение → параметры процесса → проверка и
  нарезка → сохранение. По умолчанию отчёты скрыты и работа идёт без остановок; при «Этапы работы: показывать»
  ассистент ждёт «Продолжить» или правку после каждого этапа. Автоматический режим без вопросов —
  настройка `interactive`.
- **Подбор материала по ТЗ.** Текст .docx извлекается, LLM переводит требования в ограничения, а инструмент
  `select_material` проверяет все доступные материалы по базе свойств и возвращает рекомендацию и исключённые
  материалы с причинами и источником каждого значения.
- **Проверка параметров процесса** (`check_process`): температура сопла и стола, обдув, скорость, ретракт —
  относительно профиля производителя материала (Stereotech) и технологического окна семейства (Prusa);
  слой и ширина линии относительно сопла, первый слой; закрытая камера, сушка, закалённое сопло.
- **Анализ геометрии** (`agent/geometry.py`): габариты, объём, нависания для 6 вариантов укладки, ось вращательной
  симметрии и центральное отверстие.
- **5D одной командой** (`setup_5d`): ось вращения вертикально в центр стола; если отверстие больше штатной
  оправки — режим 5D Spiral Full и диаметр базы, равный отверстию (без зазора под первыми витками).
- **Предполётная проверка**: область печати, нависания и поддержки, площадь опоры, коробление, тонкие места,
  корректность размещения для 5D.
- **Сравнение вариантов** (время, масса, стоимость в ₽), **технологическая карта** (HTML) и **рецепты** для повтора.
- **Принцип минимальных изменений**: настройки профиля меняются только по требованию ТЗ; перед новой деталью
  изменения сбрасываются.

## Устройство
| Файл | Назначение |
|---|---|
| `AIAssistant.py` | Создание агента, локальный сервер, пункт меню «Открыть чат в отдельном окне» |
| `AIStage.py`, `qml/` | Вкладка «AI Ассистент» в слайсере: панель чата на QML |
| `agent/bridge.py` | Связь панели QML с агентом (вызовы из главного потока Qt) |
| `agent/server.py` | HTTP-сервер на 127.0.0.1: веб-чат, API чата, MCP-эндпоинт `POST /mcp` |
| `agent/agent.py` | Цикл диалога с LLM: Chat Completions + tool calling |
| `agent/llm.py` | Клиент OpenAI-совместимого API (urllib, TLS с проверкой сертификата) |
| `agent/tools.py` | Инструменты слайсера — общие для LLM и MCP |
| `agent/mainthread.py` | Выполнение действий со сценой в главном потоке Qt |
| `agent/interaction.py` | Вопросы и отчёты по этапам: ожидание ответа пользователя, скрытые этапы, автоматический режим |
| `agent/geometry.py`, `materials.py`, `materials_db.json` | Анализ геометрии; база материалов и подбор |
| `agent/production.py`, `docs.py` | Стоимость, техкарта, рецепты; чтение .docx |
| `agent/prompt.py` | Правила работы ассистента (системный промпт) |
| `web/` | Чат в отдельном окне браузера (проекты и папки): HTML + CSS + JS без сборки |
| `agent/cacert.pem` | Корневые сертификаты для HTTPS к LLM (на случай устаревшего списка в Windows) |

### База материалов (`agent/materials_db.json`)
Таблицы: `sources` (источники), `references` (свойства эталонных материалов из паспортов), `levels`
(стойкость к УФ, маслам, щелочам и т.д. — с источником каждого уровня), `templates` (семейства без открытых
паспортов), `process` (технологические окна), `materials` (52 материала STE Slicer → эталон-аналог и уточнения).
Источники:
- Ultimaker, «Materialübersicht Ultimaker Filamente», TU Dresden, 2024 — механика, теплостойкость, химстойкость;
- Ultimaker PC Technical Data Sheet v5.00;
- Prusa Research, Filament Material Guide — температуры сопла/стола, камера, сушка, закалённое сопло;
- профили материалов Stereotech в STE Slicer — рекомендованные производителем температуры, обдув, ретракт, скорость.
Значения без открытого паспорта помечены `estimate` и показываются пользователю как «оценка».

MCP: JSON-RPC 2.0 поверх HTTP — `initialize`, `tools/list`, `tools/call`, `ping`.
```
curl -X POST http://127.0.0.1:<порт>/mcp -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tools/list\"}"
```

Код совместим с Python 3.5 (среда STE Slicer), внешних зависимостей нет.
